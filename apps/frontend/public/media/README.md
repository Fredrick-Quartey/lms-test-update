# Home page video

Put a licensed laundry video here and the home page plays it behind the buttons. Until then a drawn
washing-machine scene shows instead, so nothing breaks.

| File | What | Size |
|---|---|---|
| `hero.mp4` | the video (H.264, no sound, 8–15 seconds, loops) | 1280×720, under 3 MB |
| `hero.webm` | same video as WebM (optional, smaller) | 1280×720, under 2 MB |
| `hero.jpg` | one still frame, shown while the video loads | 1280×720, under 150 KB |

Free licensed videos: Pexels or Pixabay (search "laundry" or "washing machine"). Note the source and licence.
The video does not play on slow connections, with Data Saver on, or when the phone is set to reduce motion
(SRS NFR-U3, NFR-U4). Visitors can stop it with the Pause motion button (WCAG 2.2.2).
